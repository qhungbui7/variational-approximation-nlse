# Non-Conservative Variational Approximation for Nonlinear Schrödinger Equations

This repository contains a numerical implementation and comparative analysis between Full Partial Differential Equation (PDE) simulations and Ordinary Differential Equations (ODEs) derived from the Non-Conservative Variational Approximation (NCVA) framework for Nonlinear Schrödinger Equation (NLSE) solitons.

## Overview
The project extracts soliton parameters from numerical PDE data and compares them against theoretical predictions generated by the NCVA ODE model across six key parameters:
* Amplitude ($a$)
* Width ($w$)
* Position ($\xi$)
* Chirp ($b$)
* Speed ($c$)
* Phase ($\phi$)

## Key Features
* **Automated Curve Fitting:** Extracts physical spatial parameters from density profiles using optimized curve fitting.
* **Phase Analysis:** Implements phase unwrapping (`np.unwrap`) and polynomial regression (`np.polyfit`) to isolate chirp, speed, and phase evolution.
* **Comparative Visualization:** Generates side-by-side verification plots tracking all parameters over time.

## Requirements
* Python 3.x
* NumPy
* SciPy
* Matplotlib

## Usage
Run the main script to execute the simulation and generate the comparison plots:
```bash
python main.py


```
